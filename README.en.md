## What is MD Viewer?

AI is changing how documents are written — plans, notes, API specs, manuals: more and more arrive as `.md`.

**MD Viewer is an ultra-lightweight local Markdown reader for Windows.**

## Why MD Viewer?

- **Fast**: cold-starts in a blink; hundred-page documents and heavy diagrams scroll smoothly
- **Complex diagrams, finally readable**: a 30-node flowchart or a 10-table ER model — double-click into the fullscreen canvas: vector zoom, drag pan, one-click re-orientation, crisp at any size
- **Beautiful and easy**: four poetic themes (Pure Snow · Forest Whisper · Warm Amber · Starry Night); F11 Zen mode folds everything away — reading docs feels like reading a book
- **Knows engineers' repos**: AI-tool folders like `.claude`, `.github` and `.trellis` show up automatically when they contain Markdown
- **It remembers where you stopped**: close and reopen — you're back at the heading you left
- **Zero-compromise privacy**: everything renders locally; your documents never leave your machine

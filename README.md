## 什么是 MD Viewer？

AI 正在改变文档的写法——方案、笔记、接口说明、操作手册，越来越多以 `.md` 交付。

**MD Viewer 是 Windows 上专为 Markdown 打造的极轻量的本地阅读器。**

## 为什么选它？

- **轻快**：冷启动秒开，百页文档与复杂图表流畅滚动
- **复杂架构图看得清**：几十节点的流程图、十几张表的 ER 图，双击进全屏画布——矢量缩放、拖拽平移、一键横竖换向，怎么放大都不糊
- **好看好用**：素雪初霁 · 森之轻语 · 琥珀暖阳 · 星夜沉幽四套主题一键切换；F11 禅阅模式收起所有干扰，读文档像读一本书
- **懂工程师的仓库**：`.claude`、`.github`、`.trellis` 这类 AI 工具目录，里面有文档就自动显示
- **它记得你读到哪**：关掉重开，回到上次读到的那个标题
- **隐私零妥协**：纯本地渲染，文档永不出你的电脑

## ✨ 核心亮点

| | | |
|---|---|---|
| 🧭 **图表引擎**<br>Mermaid / PlantUML 双击全屏，滚轮**无损缩放**、拖拽平移，单图导出 SVG / PNG | 🗂 **多标签**<br>同屏并行多篇文档，**毫秒级切换**零重渲，会话重启自动恢复 | ⌨️ **效率至上**<br>`Ctrl+P` 模糊搜索快速打开、`Ctrl+Tab` 循环切换、拖拽排序标签 |
| 👁 **源码模式**<br>`Ctrl+/` 整文档一键切换渲染 / 源码，全文复制、行数统计 | 📐 **排版精工**<br>代码行号严格对齐、KaTeX 数学公式、脚注、`[TOC]` 目录、行内搜索 | 📤 **专业导出**<br>PDF（等待图表渲染完成）、单文件 HTML（图片内联、主题跟随） |
| 🌲 **文件夹工作区**<br>侧边栏目录树 + 可折叠大纲，外部修改实时刷新 | 🎨 **深度可调**<br>明暗主题、6 档代码高亮、字号 / 字体 / 阅读宽度随心 | 🔒 **本地优先**<br>文档不上传；PlantUML 联网渲染需你明确同意；正版授权防篡改 |

## ⌨️ 快捷键速查

| 按键 | 功能 | 按键 | 功能 |
|---|---|---|---|

## 🔒 隐私承诺

你的文档**始终在本机处理**——MD Viewer 不上传任何文档内容。仅有的两处网络行为均可控：更新检查（访问 GitHub 获取版本信息）与 PlantUML 图表联网渲染（默认每次询问，可完全关闭）。
